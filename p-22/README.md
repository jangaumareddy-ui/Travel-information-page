# 🌍 Travel Information Page

## 📌 Project Description

The Travel Information Page is a simple HTML project created to provide
information about popular travel destinations in India.

This project is designed for beginners to practice basic HTML concepts
such as headings, paragraphs, images, links, lists, tables and forms.

## 🎯 Objectives

- To create a simple travel information webpage.
- To display information about popular destinations.
- To practice HTML headings and paragraphs.
- To use images in an HTML webpage.
- To create lists and tables.
- To create a simple contact form.
- To understand the basic structure of an HTML webpage.

## 🛠️ Technologies Used

- HTML5
- Web Browser

## 📂 Project Structure

```text
travel-information-page/
│
├── index.html
└── README.md
````

## ✨ Features

* Home section
* Popular destinations
* Travel tips
* Travel checklist
* Destination selection
* Contact form
* Navigation links
* Travel image

## 🗺️ Destinations Included

1. Taj Mahal - Agra
2. Goa
3. Kerala
4. Hyderabad
5. Jaipur

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html`.
4. The Travel Information Page will open in your web browser.
